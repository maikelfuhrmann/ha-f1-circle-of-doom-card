# Circuit defaults

Green-flag values below are published pit-stop time-loss estimates from Formula1.com's race previews, checked on 8 November 2026. They are starting assumptions, not guaranteed measurements for the current race. A stop includes pit-lane travel and service; several previews explicitly assume 2.5 seconds stationary. Changing conditions, regulations and pit-lane layouts can change the loss.

**VSC values are modelled placeholders, not published or measured VSC losses.** This release uses 65% of each circuit's green-flag baseline, rounded to 0.1 seconds. That heuristic is not a physical simulation and will be inaccurate at some circuits. Adjust it when a better estimate is available. It assumes VSC remains active throughout the stop; a transition to green can remove the saving. For an example of this risk, see [Williams' account of the 2021 São Paulo GP](https://www.formula1.com/en/latest/article/what-the-teams-said-race-day-in-sao-paulo-2021.W75mqEMWUxoK3sb11emoM).

The card identifies circuits by exact normalized names or aliases from F1 Sensor's `circuit_short_name` and `meeting_location` attributes. Accents, spaces and punctuation are ignored. It never infers a circuit from a country or Grand Prix title (which may be ambiguous). The optional YAML `circuit` setting overrides detection.

For unknown circuits, including Madrid where the [2026 preview](https://www.formula1.com/en/latest/article/need-to-know-the-most-important-facts-stats-and-trivia-ahead-of-the-2026-spanish-grand-prix-madrid-madring.0VbYQHCnrBCibxbkwygP0) does not give a pit-loss value, the card clearly labels the generic YAML fallback. User changes are saved separately for that unknown name too. Missing metadata never reuses another circuit's settings.

To update a baseline, edit `src/presets.js`, this table, and rebuild. Existing manual overrides take precedence until the user resets them.
